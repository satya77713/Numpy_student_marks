# 📊 Task 11: NumPy Student Marks Analysis

## 📌 Project Overview

This project demonstrates how to use **NumPy** in Python to perform numerical analysis on student marks.

A NumPy array is created to store student marks, and several statistical calculations are performed to understand the data.

This project was completed as part of **Task 11 (Level 1, Day 11)** of the AI & ML Internship at **Veda Technology**.

## 🎯 Objective

To learn how NumPy can efficiently perform numerical calculations and statistical analysis in Python.

## 🛠️ Technologies Used

- Python
- NumPy
- Google Colab
- GitHub

## 📚 Project Features

1. Import the NumPy library.
2. Create a NumPy array containing student marks.
3. Calculate the mean (average).
4. Calculate the median.
5. Find the minimum mark.
6. Find the maximum mark.
7. Calculate the standard deviation.
8. Display and explain the statistical results.

## 📊 Dataset

The project uses manually created sample marks for 10 students.

```python
student_marks = np.array([85, 90, 78, 92, 88, 76, 95, 89, 84, 91])
```

No external dataset is required.

## 🧮 Statistical Calculations

| NumPy Function | Purpose |
|---|---|
| `np.mean()` | Calculates average marks |
| `np.median()` | Calculates median marks |
| `np.min()` | Finds the lowest mark |
| `np.max()` | Finds the highest mark |
| `np.std()` | Calculates population standard deviation |
